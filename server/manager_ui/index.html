Updates

A new release of the game needs the same release on the server. The manager can do it by itself: it tells the players, waits, installs the release and starts your servers again.

Starting

        
        
        
To start the manager with a Linux machine, save this as a systemd user unit (~/.config/systemd/user/bf1943-server.service), then run: systemctl --user enable --now bf1943-server

        

      

      

        
This page from another machine

        
The page answers only on this machine. To use it from another one, set a password first, then open it to your network. The manager must be started again for that to take hold.
